# Test Execution - Atividade 4

Este arquivo descreve como executar e registrar os testes relacionados a esta atividade.

## Testes existentes

- Arquivo de teste: `test/NotificationServiceTest.java`
- Objetivo: validar o comportamento de `NotificationService.notifyLoanCreated(...)`
- O teste deve ser executado via Maven no projeto `library-maintenance-lab`.

## Como rodar

1. Abra o terminal na pasta `library-maintenance-lab`
2. Execute:

```bash
mvn -q test
```

Se o comando `mvn` nao estiver instalado, execute o teste diretamente pelo IntelliJ ou use um Maven Wrapper se estiver disponivel.

3. Resultado esperado: todos os testes passam e o build termina sem erros.
